## Why

KnowStruct 的所有 P0 业务都需要明确的用户与个人工作区边界，但当前应用只有未受保护的前端占位路由和后端健康检查，已有账号无法安全进入产品。先建立范围受控的密码登录与会话能力，才能让后续 Project、Node、Source 和 Entry 数据可靠地归属到当前用户。

## Appetite

5 至 7 个工作日。若超出投入边界，优先削减非关键视觉润色和辅助 CLI 命令，不削减密码安全、会话撤销、路由保护及核心验收测试。

## What Changes

- 支持部署人员通过命令行预置账号，并在创建账号时建立默认个人工作区。
- 新增桌面端和移动端共用的响应式账号密码登录页，覆盖必填、提交中、统一错误和成功跳转状态。
- 新增可过期、可撤销的服务端登录会话；支持浏览器会话和“保持登录”两种有效期。
- 新增当前用户查询与退出登录能力，并保护所有现有业务 API 和前端业务路由。
- 支持页面刷新后的会话恢复，以及登录后返回原目标业务页面。
- 建立后续领域模型可复用的数据库连接、迁移和当前用户依赖基础。
- 本次不提供用户注册、自助找回或修改密码、第三方登录、多工作区切换、成员角色权限、会话管理页面或 PWA 安装能力。

## Capabilities

### New Capabilities

- `password-authentication`: 已预置账号的密码登录、默认个人工作区、可撤销会话、当前用户恢复、受保护访问和退出行为。

### Modified Capabilities

无。

## Impact

- 后端：数据库会话与 Alembic 环境、用户/工作区/认证会话模型、密码安全服务、账号管理 CLI、认证 API 和 `get_current_user` 依赖。
- 前端：登录路由和页面、认证状态初始化、受保护路由、Cookie 凭据请求、退出入口及认证错误处理。
- 数据库：新增用户、默认个人工作区和认证会话相关表及索引。
- 依赖与配置：新增密码哈希依赖，以及 Cookie、会话有效期、可信 Origin 和登录限流配置；生产环境必须使用 HTTPS 和安全 Cookie。
- 测试：新增认证 API、会话生命周期、路由保护及桌面/移动登录流程测试。
