## Context

当前微调为一次性指令：草稿 + 意图说明 + 意见 → 增量动作清单。模型改写节点名或臆造层级时
整批失败，用户体验差。本次改为「全量历史会话 + 完整目标树工具调用」，复用既有目录约束
校验（≤6 层、同级标准化唯一、名称/说明长度），并把校验失败从死路变成可纠正回合。

## Goals / Non-Goals

**Goals:**

- 每个草稿一个会话，支持自由讨论与修改，修改结果通过结构化工具调用确定性写入候选树。
- 校验失败可自愈（有界重试），不静默修复，不污染候选树。
- 确认采用边界不变；历史有界，成本可控。

**Non-Goals:**

- 流式输出、通用聊天、多模型按任务选择、跨草稿会话。

## Decisions

### 1. 消息持久化

新表 `directory_draft_messages`：id、draft_id（FK CASCADE）、role（user/assistant/system）、
content（Text）、created_at。redraft 删除该草稿全部消息；discard/确认后保留草稿与消息
供追溯，但会话入口关闭。迁移 + 真实 MySQL 验证。

### 2. 会话轮协议（替换 /refine）

`POST /drafts/{id}/messages {content}`（content 1-2000 字符，strip 后非空）：

1. 追加 user 消息；
2. 组装上下文：system 提示（任务边界 + 目录约束 + 工具约定）+ 当前候选树 JSON 快照
   （每次调用都注入最新树，含手动预览改动）+ 全量历史（最近 10 轮完整，更早压缩为摘要）；
3. 调用带工具 `apply_directory_tree(tree: nested JSON)` 的 chat（DeepSeek/豆包
   OpenAI 兼容工具调用；实现前先用真实 key 验证连通性）；
4. 解析 `tool_calls`：有调用 → 校验树 → 通过则替换候选树并追加 system 反馈
   「已应用，共 N 个节点」；不通过则追加 system 反馈列出具体违规，再重试（≤2 次）；
   无调用 → 仅返回文字；
5. 返回更新后的 DraftResponse + 消息列表。

### 3. 树与约束

- 完整目标树用嵌套 JSON（name/description/children），无 id → 无环；
- 校验：strip 后名称 1-100、说明 ≤1000、每层同级 normalized_name 唯一、根到最深 ≤6；
- 校验失败回写具体原因（含路径），模型基于反馈重输出；仍失败转人工，草稿保持可编辑；
- 确认采用仍走既有 `confirm_draft` 二次校验与事务创建。

### 4. 历史有界与意图摘要

- 保留最近 10 轮完整消息；更早消息由模型压缩为一段「早期意图摘要」存回
  `intent_note`（失败回退为丢弃最早轮次）；会话轮次上限 30，超限提示开启新会话/重新起草；
- `intent_note` 字段保留，不再作为独立 UI 概念。

### 5. 前端交互

- DraftPanel 改为「树 + 会话」双区：桌面左右、移动上下（390px 不横向溢出）；
- 消息气泡含角色与「已更新目录」标记；输入框发送后置等待态，禁用重复提交；
- 会话失败（网络/非法 JSON/超时）在会话区显示可读错误，可重发；草稿树保持上次成功状态。

### 6. 失败与重试

- 模型返回非法 JSON → 复用容错解析；仍失败该轮报错，会话保留可重发；
- 工具调用校验失败 → 结构化反馈 + ≤2 次自愈重试；超限转人工；
- 模型超时（沿用 300s）→ 该轮失败，会话保留；
- 重复提交同一消息不重复创建节点（消息幂等由客户端防重复 + 确认幂等兜底）。

## Risks / Trade-offs

- [全量历史每轮重发，token 成本随轮次增长] → 最近 10 轮完整 + 早期摘要 + 会话上限 30；
  用户已接受该取舍以换取讨论与自愈能力。
- [模型不调用/乱调用工具] → system 提示明确「修改才调用、讨论不调用」；用户可说「应用」
  触发；乱调用由严格校验与反馈纠正。
- [工具调用不被某模型支持] → 实现前连通性 spike；不支持则退回「约定标记块」解析兜底。
- [完整树覆盖手动预览改动] → 每次注入当前最新树，模型基于最新状态输出；UI 提示应用后预览
  以 AI 输出为准。
- [会话轮延迟敏感] → v1 不做流式，等待期间显示等待态；文档注明应使用快文本模型
  （多模型选择属 E15）。

## Migration Plan

- 新增 `directory_draft_messages` 表；迁移在真实 MySQL 验证。
- 移除 `/refine` 接口与旧前端「调整意见」区；`intent_note` 保留字段。
- 回滚为撤销合并（消息表随迁移回滚删除）。
