## Why

第一轮 UI 设计稿（登录、项目列表、项目与知识目录工作区）已经评审定稿（`docs/prototypes/ui-refinement`），但当前前端仍是早期功能骨架，视觉和交互与设计稿不一致。现在把已评审的设计基线落地到真实前端，让 P0 现有页面在桌面和移动端呈现统一、克制、专业的视觉，并为后续垂直切片提供稳定的 UI 基线。

## What Changes

- 视觉基线：按设计稿更新全局 token（主色 `#2767D8`、页面背景、文字层级、4-8px 圆角、状态语义色），应用到登录、项目列表、工作区三处。
- 登录页：按设计稿细化桌面/移动布局与表单状态（默认 / 错误 / 加载中）。桌面端设计稿中的"最近维护"上下文面板**不实现数据内容**（认证前不得暴露业务数据，见 Non-Goals），登录页仅做视觉细化。
- 项目列表页：
  - 移除页头"个人工作区"小标签与"每个项目独立维护知识目录。"说明；
  - "创建项目"按钮缩小，桌面在右上角、移动端改为右上角小按钮（不再占整行）；
  - 无项目空状态改为纯说明 + 引导文案（指向右上角「创建项目」），移除"创建第一个项目 / 前往采集箱"按钮；**BREAKING**：变更主规格"无项目状态"场景；
  - 创建/编辑项目弹窗把"项目目标"和"背景"合并为单个"项目目标与背景"字段（≤500 字符，映射到现有 `goal`），`background` 字段不再通过 UI 暴露；**BREAKING**：变更主规格项目字段行为；
  - 删除确认弹窗标题与按钮统一格式（`删除"X"项目？` / `删除项目`）；桌面表格与移动卡片文案统一为"目录节点"。
- 项目与知识目录工作区页：
  - 顶栏移除"新建节点"主按钮，"项目设置"改为图标按钮，计数统一为"X 个目录节点"；
  - 目录面板头部去掉副标题，保留"知识目录"标题 + 创建根节点图标；
  - 节点头部去掉"知识节点"小标签，操作按钮统一为"编辑节点 / 创建子节点"，选中节点时页面只保留一个主操作；
  - 创建/编辑节点弹窗移除"节点说明"字段，弹窗标题与"上级节点"文案按设计稿统一；**BREAKING**：节点说明由可编辑改为仅展示；
  - 空目录 / 空节点文案统一为"手动创建节点，不会自动采用 AI 目录。"，操作统一为蓝色主按钮；空节点内容区不再重复放置按钮；
  - 移动端节点头部增加节点菜单入口（⋯），与桌面节点菜单能力对齐；移动端"上一层"逐级返回保持现有实现并纳入验证；
  - 移动端顶栏改为"状态 + 标题一行、节点数第二行"的布局。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `project-management`：无项目空状态从"主操作 + 采集入口按钮"改为"说明 + 右上角创建引导"；项目创建/编辑从"目标 + 背景"两个字段改为单个"项目目标与背景"字段（≤500 字符），背景不再通过 UI 暴露。
- `knowledge-directory`：节点说明由"可编辑"改为"P0 仅展示、不提供编辑"；创建/编辑节点弹窗仅保留名称字段；空目录/空节点文案与操作统一；移动端补齐节点菜单入口。

## Impact

- 前端：`frontend/src/index.css`（设计 token 与响应式样式）、`LoginPage`、`HomePage`、`ProjectDetailPage`、`Layout`、`projects/*` 弹窗与菜单组件，以及对应测试（`HomePage.test.tsx`、`ProjectDetailPage.test.tsx`、`LoginPage.test.tsx`）。
- 后端：无 API / 模型变更；字段映射沿用现有 `goal` / `background` / `description` 字段。
- 规格：`project-management`、`knowledge-directory` 两个主规格的 delta spec。
- 设计源：`docs/prototypes/ui-refinement`（Round 01 评审稿与截图）作为视觉与交互基线。
