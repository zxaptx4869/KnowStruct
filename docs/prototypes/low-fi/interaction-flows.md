# KnowStruct 核心交互流程

## 1. 流程 0：账号密码登录

```text
输入已有账号和密码
→ 校验必填项
→ 校验账号与密码
→ 成功后建立会话
→ 进入项目列表
```

P0 不提供用户自助注册、找回密码或第三方登录。账号由部署人员通过交互式 CLI 预置；普通登录使用最长 24 小时的浏览器会话，“保持登录”为固定 30 天；退出撤销当前会话，部署人员重设密码时撤销该账号全部会话。

## 2. 流程 A：手机快速采集

```text
全局“采集”或项目内“添加资料”
→ 选择截图 / 链接 / 文字
→ （可选）选择项目；允许暂存为“未分配”
→ 保存 Source
→ 上传 / OCR / AI 提取状态时间线
→ 成功进入待确认队列，失败可重试
→ 归档前必须确认项目
```

关键判断：保存原始来源是第一成功点。即使后续 OCR 或 AI 失败，Source 仍存在，不要求用户重新上传。

## 3. 流程 B：AI 提取确认

```text
打开待确认 Source
→ 同时查看原始来源和候选总数
→ 逐条编辑 Extraction 的类型、内容、适用条件和建议节点
→ 每条接受或拒绝
→ 未决定的候选保留在队列
→ 完成本资料
→ 被接受的候选生成 Entry，并保留 Source 关联
```

推荐逐条确认。桌面端可以快速连续处理，但“完成本资料”不能代替每条候选的决定。低置信度或缺少适用条件时明确提示，不默认选中“接受”。

## 4. 流程 C：知识查询和来源追溯

```text
进入项目
→ 展开多级知识目录
→ 选择节点
→ 查看该节点的正式 Entry
→ 按经验 / 参数 / 商品 / 避坑过滤
→ 打开 Entry
→ 查看关联 Source
→ 桌面抽屉或移动整页查看原图、链接、文字与证据位置
```

来源入口需要同时显示来源类型、可用状态和采集时间，避免用户点开后才发现链接失效。

## 5. 流程 D：搜索

```text
输入关键词
→ 查看 Entry 与 Source 命中
→ 按项目、节点、类型、状态筛选
→ 打开正式 Entry
→ 回到所属节点，或打开原始 Source
```

P0 搜索以正式 Entry 为主要结果，Source 命中作为证据提示。无结果时保留当前关键词与筛选，并提供“清除筛选”，不提供 AI 编造答案。

## 6. 流程 E：Review（P1 方向稿）

```text
从全局 Review 查看跨项目问题，或从项目内入口查看当前项目
→ 选择冲突 / 缺少条件 / 缺少来源
→ 并排对比相关 Entry 和 Source
→ 查看 AI 建议（候选）
→ 补充适用条件或拒绝建议
→ 用户确认修改
→ 标记 Finding 已解决
```

Review 的“接受建议”只进入编辑确认步骤，不直接修改正式 Entry。

## 7. 关键状态矩阵

| 状态 | 界面反馈 | 可用动作 | 数据约束 |
|---|---|---|---|
| 登录信息未填写 | 表单内提示账号和密码必填 | 补充后重新登录 | 不发起认证请求 |
| 账号或密码错误 | 使用统一错误文案 | 重新输入 | 不暴露账号是否存在 |
| 登录成功 | 进入项目列表 | 继续使用、退出登录 | 建立有效会话 |
| 首次使用 / 没有项目 | 解释项目是归档边界 | 创建项目、仍可全局采集 | Source 可暂存未分配 |
| 没有目录节点 | 空目录提示 | 手动添加节点 | 不自动采用 AI 目录 |
| 上传中 | 进度和文件名 | 取消 | 尚未完成的文件不进入处理 |
| OCR 处理中 | 时间线当前步骤 | 离开页面 | Source 已保存 |
| AI 提取中 | 显示正在生成候选 | 离开页面 | 不创建 Entry |
| 处理失败 | 失败原因和失败步骤 | 重试、保留原始来源 | 重试不得复制 Source |
| 待用户确认 | 候选数量和低置信度提示 | 打开确认 | 不自动归档 |
| 部分内容被拒绝 | 显示接受/拒绝/未决定统计 | 继续确认、完成 | 只为接受项创建 Entry |
| 没有搜索结果 | 保留关键词和筛选 | 清除筛选、改关键词 | 不生成无依据答案 |
| 来源链接失效 | 显示失效状态和采集快照 | 重试访问、查看已保存文本 | Entry 与来源关系保留 |

## 8. 原型中的可点击路径

- D00 → D01、M00 → M01：已有账号登录。
- M01 → M02 → M03 → M04 → M05 → M06 → M08：完整手机采集到追溯闭环。
- D01 → D02 → D03 → D07：桌面目录浏览和来源追溯。
- D04 → D05 → D03：桌面待确认资料归档。
- D06 → D03 / D07：搜索到节点或来源。
- D08：P1 Review 冲突处理方向。
- D09：P1 决策和预算的项目内位置。
