# KnowStruct 低保真信息架构

## 1. 设计判断

第一版不把产品组织成一组平级功能，而是围绕两种上下文展开：

1. 全局上下文负责跨项目进入、快速采集、全局搜索和问题聚合。
2. 项目上下文负责目录整理、资料处理、正式记录、决策和预算。

这样既允许手机端“先收进来”，又避免桌面端在整理时失去项目和目录上下文。

## 2. 推荐信息架构

```text
KnowStruct
├── 登录（P0，已有账号 + 密码）
├── 项目
│   ├── 项目列表
│   └── 项目工作区
│       ├── 目录（默认）
│       ├── 资料（Source 与处理队列）
│       ├── 记录（Entry 聚合列表）
│       ├── Review（P1，当前项目过滤）
│       ├── 决策（暂缓，2026-08）
│       └── 预算（暂缓，2026-08）
├── 采集箱（全局 Source 入口，可选项目）
├── 搜索（全局，支持项目/节点/类型/状态筛选）
├── Review（P1，全局问题聚合）
└── 我的
```

与草案相比的调整：

- “资料”和“记录”保留为项目内两个独立视图。资料是原始 Source 及处理状态，记录是已确认 Entry，不能混为一个列表。
- Review 同时存在全局聚合入口和项目内过滤入口，但两者指向同一对象，不形成两套数据。
- 决策和预算只在项目内部出现；功能当前暂缓（2026-08-07 决定），不进入全局主导航。
- “目录”是项目默认工作区；节点详情属于目录上下文，不再成为孤立页面。

## 3. 核心对象边界

| 对象 | 用户可见名称 | 何时产生 | 是否正式知识 | 关键关系 |
|---|---|---|---|---|
| Source | 原始来源 / 资料 | 上传截图、保存链接或输入文字后 | 否 | 可产生多个 Extraction，可支持多个 Entry |
| Extraction | AI 候选 | OCR/解析和 AI 提取后 | 否 | 必须由用户编辑、接受或拒绝 |
| Entry | 正式记录 | 用户接受候选或手动创建后 | 是 | 归档到一个节点，可关联多个 Source |
| Decision | 决策 | 用户基于记录和来源做出选择后 | 是，P1 | 关联多个 Entry 和 Source，记录理由与约束 |

界面必须持续显示对象类型，尤其不能用“资料”“记录”“AI 结果”互相代称。

## 4. 桌面端布局

推荐采用三段式工作区：

```text
全局导航 208px | 项目上下文/目录树 280px | 内容工作区 自适应
```

- 全局导航负责稳定定位。
- 目录树负责项目层级和节点切换。
- 内容区负责记录扫描、编辑、批量处理和比较。
- 查看来源时从右侧打开 420px 抽屉；需要集中查看时可进入独立来源页 D07。

项目“资料、记录、Review、决策、预算”视图不需要目录树时，中栏改为该视图的筛选与队列，不改变整体空间模型。

## 5. 移动端布局

底部导航保留五项：

```text
项目 | 采集 | 搜索 | Review | 我的
```

- “采集”位于中间并强化为主要动作。
- Review 标记 P1，在方向稿阶段保留位置以验证导航容量。
- 目录在项目页面内部逐级进入，不塞入底部导航。
- 来源预览使用整页返回模式，避免窄屏抽屉。

## 6. 端侧职责

| 任务 | 移动端 | 桌面端 |
|---|---|---|
| 快速截图/链接/文字采集 | 主任务 | 支持拖放和批量上传 |
| 选择项目 | 可选，归档前必选 | 推荐采集时选择 |
| 查看处理状态 | 简明时间线 | 队列、筛选和批量重试 |
| AI 候选确认 | 单条、轻量编辑 | 多条比较、完整字段编辑 |
| 目录维护 | 浏览和轻量新增 | 主任务，支持层级整理 |
| 知识查询 | 节点摘要与来源查看 | 列表扫描、筛选、批量操作 |
| Review/决策/预算 | 查看与轻量处理 | 主任务（P1） |

## 7. 页面映射

| 编号 | 页面 | 主要目的 |
|---|---|---|
| D00 / M00 | 账号密码登录 | 已有账号进入产品，验证必填、错误和成功状态；不提供注册 |
| D01 / M01 | 项目列表 | 进入项目并验证无项目空状态 |
| D02 | 项目工作区与知识目录 | 目录层级、项目内导航和空节点状态 |
| D03 / M06 | 节点详情与正式记录 | 扫描 Entry 并追溯 Source |
| D04 / M04 | 采集箱/待确认队列 | Source 状态和处理入口 |
| D05 / M05 | AI 提取确认 | Extraction 编辑、接受和拒绝 |
| D06 / M07 | 搜索结果 | 过滤、打开 Entry、回节点或来源 |
| D07 / M08 | 来源详情 | 原始内容、处理时间线和关联 Entry |
| D08 | Review 冲突处理 | P1 问题、证据与建议 |
| D09 | 决策与预算位置 | P1 项目内导航与摘要方向 |
| M02 / M03 | 快速采集/处理状态 | 手机端采集主流程 |
