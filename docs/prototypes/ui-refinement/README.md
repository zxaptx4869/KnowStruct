# KnowStruct UI Refinement - Round 01

## 设计目标

本原型用于评审第一轮 UI 优化方向，不连接真实 API，也不复制生产业务逻辑。设计关键词是克制、清晰、专业、可扫描和工作效率导向。

- 桌面端保持 `208px 全局导航 + 280px 项目目录 + 自适应内容区`。
- 移动端以 390px 为基准，保留底部导航，目录在项目内逐级浏览。
- 保留已实现的登录、项目管理和普通目录树能力，不增加新业务功能。
- 蓝色只用于主要操作和选中状态；成功、警告、危险使用独立语义色。
- 控件采用 4-8px 圆角，避免卡片套卡片、装饰性渐变和低信息密度。

## 使用方式

从仓库根目录运行：

```bash
python3 -m http.server 4173 --directory docs/prototypes/ui-refinement
```

然后访问 `http://127.0.0.1:4173/`。

顶部评审控制台可切换页面、页面状态和 `1440 x 900`、`1280 x 800`、`390 x 844` 三种视口。页面内部的主要按钮、菜单、目录节点和弹窗关闭操作也可点击。

## 规格边界说明

- 项目列表仅展示主规格允许的项目状态、真实目录节点数和更新时间，不展示尚未实现的资料数、记录数或待确认数。
- Review/P1 导航位置沿用当前低保真决策和现有实现，本原型不扩展 Review 业务能力。
- 移动端不提供目录拖拽；拖拽状态只在桌面视口展示。
- AI 不参与目录生成，空目录只提供手动创建节点入口。
